# Industrial Instruction Model Card

## 模型

- 版本：`industrial-char-tfidf-logreg-v2-recovery`
- 文件：`models/industrial_instruction.joblib`
- 输入：中英文单条工业操作指令
- 输出：七类意图概率；槽位和任务序列由可审计 grounding 层生成
- 规模：约 320 KB（327,256 bytes）

## 数据与评估

训练集 2,864 条，测试集 396 条。数据覆盖螺丝刀、扳手、滚柱、螺栓、螺母、手电筒及料箱/工具箱/包装箱/托盘，中英文模板、空间限定、放置恢复和礼貌噪声。测试采用未出现在训练集中的完整句式模板，但关键工业动词可能在其他训练句式中出现。

Accuracy 为 100.00%，Macro-F1 为 100.00%；规则基线 Accuracy 为 31.82%，Macro-F1 为 28.21%。详细分类报告和混淆矩阵以 `reports/instruction_model_metrics.json` 为准。规则基线只包含一组固定动作关键词，用作现有启发式选择器的对照，不代表最强规则系统。

## 使用边界

模型只做意图判断，不应凭空补齐缺失的对象或目的地。置信度低于阈值、对象不在本体、指令矛盾或场景 grounding 不唯一时必须拒绝执行。该指标来自合成模板，不应外推为真实工厂语音、方言、ASR 噪声或安全指令上的 99% 性能。

## 风险与改进

当前不支持复杂否定、条件、数量、多对象排序和跨句指代。上线前需加入真实操作员语料、对抗/歧义集和 OOD 检测，并把“停止/急停”交给独立高优先级安全通道，不能只依赖统计模型。
